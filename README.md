# Диагностика гибких навыков

Веб-приложение для диагностики гибких навыков ребёнка по результатам беседы с родителем.

## Запуск локально

```bash
npm install
npm run dev
```

Открыть http://localhost:5173

## Сборка для продакшена

```bash
npm run build
```

Результат окажется в папке `dist/`.

## Деплой

Этот проект полностью совместим с Vercel, Netlify, Cloudflare Pages и GitHub Pages.
